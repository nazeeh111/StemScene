# Audio contract

- Import admits bounded WAV/FLAC lossless media, preserving a byte-for-byte source copy and SHA-256. Project arrays use `(samples, channels)` float64. Source sample count, declared rate and channels remain authoritative.
- The learned engine currently accepts mono. The project/edit/export core supports mono and stereo arrays, but this is not a claim of stereo source separation.
- AudioSep and learned refinement operate at 32 kHz. SciPy polyphase FIR resampling uses a Kaiser window with beta 5, compensated linear-phase group delay, constant edge padding and explicit right trimming/padding to the original length. There is no fitted delay from clean references and no loudness normalization. Bandwidth lost by model-rate resampling cannot be restored by upsampling.
- AudioSep uses five-second windows with two-second overlap and positive Hann overlap-add weights. The refiner uses a centered periodic-Hann STFT; its short and bounded long-context policies are described in `refinement-method.md`. This is offline processing, not causal live streaming.
- Stable layer IDs persist across edits and revised estimates. Exact duplicate descriptions group. Locked arrays remain byte-for-byte unchanged when adding requests. Highly overlapping new requests against a lock produce an explicit conflict rather than silent reassignment. Anchors refer only to time spans in the mixed recording; model similarity is not proof of isolation.
- Every project has `residual = original - sum(stems)`. This algebraic identity is independently checked in actual exported WAVs. It says nothing by itself about correct attribution.
- An edit applies `original + sum((gain_envelope - 1) * estimated_stem)`. Fades occur inside the selected half-open sample span. Samples outside all edits are not arithmetically changed in the decoded render. Saved event IDs allow gain/span replacement without stacking another operation; separate events deliberately multiply where they overlap. Removing an event is undoable. Persisted undo restores the preceding state, including gains and identities.
- Default exports use DOUBLE (float64) WAV. FLOAT (float32) is available with explicit quantization. Actual WAV round trips must meet fixed maximum absolute amplitude errors: DOUBLE `1e-12`, FLOAT `1e-6`, for unity reconstruction, edited replay, saved mix and decoded original. Incompatible extreme cancellation or precision is rejected before publication. The manifest records measured errors and tolerance.
- Mix peak policy is explicit: reject above unity by default, preserve out-of-range floating samples when chosen, or hard clip only the final mix when chosen. Hard clipping is rejected if it would change any unedited original sample. Stems are never secretly normalized. Browser audition uses FLOAT WAV and the browser/device playback path; listening is not a bit-exact export verification.
- Defaults bound the source to 256 MiB, duration to 600 seconds, decoded arrays to 512 MiB, project arrays to 2 GiB, learned queries to eight, and inference chunks to at most ten seconds. CPU/MPS latency and memory vary with the recording and shared machine. Cancellation is checked between bounded model chunks; it is not an immediate interruption of a running kernel.

The manifest and WAV envelopes are sufficient to replay an edit without model weights. The original source bytes are included in exports. The separate clean-reference evaluator is not needed for replay.
