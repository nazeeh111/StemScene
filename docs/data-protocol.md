# Frozen controlled-mixture protocol

`scripts/prepare_esc10.py` prepares the official 400-clip ESC-10 subset from pinned upstream commit `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6`. The [metadata](https://github.com/karolpiczak/ESC-50/blob/33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6/meta/esc50.csv) contains category labels and original recording IDs. The [license](https://github.com/karolpiczak/ESC-50/blob/33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6/LICENSE) explicitly licenses this subset as CC BY 3.0 and contains per-clip provenance. Full ESC-50 has different terms. Retain dataset and individual-source attribution with redistributions and examples.

Preparation requires explicit `--download` to make public network requests. Normal inference never downloads or uploads a recording. The cache is outside the repository by default. A complete preparation fetches about 176.4 MB of genuine source WAVs, verifies the fixed metadata/license hashes, validates each WAV and records individual audio hashes in `data/esc10-split.json`. Existing frozen manifests are reused only if byte-identical; a different candidate refuses to overwrite them.

```sh
STEMSCENE_STUDY=/absolute/path/to/study
python scripts/prepare_esc10.py --download \
  --cache "$STEMSCENE_STUDY/sources" --manifest data/esc10-split.json \
  --materialize "$STEMSCENE_STUDY/mixtures"
```

Materialization additionally needs NumPy and soundfile from the installed STEMSCENE environment. To validate an existing cache and reproduce the manifest without network, omit `--download`. Choose a fresh materialization directory. Temporary audio can be reacquired from recorded URLs and hashes; the metadata-only frozen manifest remains in the repository.

The source split starts with folds 1–3 for training, 4 for selection, and 5 for confirmation. Confirmation uploaders take priority, so remove them from selection; remove all original fold-4/fold-5 uploaders from training. Uploader IDs are URL-decoded and case-folded. The script asserts disjoint original recordings, uploaders and byte hashes. Result: 222/74/80 clips. All ten classes remain present. Multiple takes from the same original recording remain together. Development smoke files stay outside confirmation.

The frozen seed `20261029` creates 30 training, 10 selection and 20 confirmation recipes. Each sums three full five-second source recordings with deterministic declared gains. Category triples are disjoint across splits, testing unfamiliar combinations. Every third recipe replaces one requested category with an absent one. Request order is shuffled. The three requests alone do not reveal which are present. Missing target labels, source filenames, clean waveforms, gains and edit ideals live only in the evaluator side. The engine receives `inference/mixture.wav` and `inference/request.json`. No clean-source-informed anchors are supplied.

Each generated source is scaled by its frozen gain, then all sources share one explicitly recorded factor if needed to bound the mixture peak to 0.9. References and mixture are saved as float64 WAV at 44.1 kHz mono. Materialization independently reads and recombines references and requires sample-exact equality with the saved mixture. This is a controlled dataset creation policy, not product loudness normalization. The product must separately preserve imported gain and sample alignment through any backend resampling.

Clean references and presence labels can supervise refiner training and evaluate outputs; they must not be inference inputs. Confirmation sources/recipes must not be inspected to tune losses, thresholds, architecture or training duration. Select those on training/selection, then run the frozen confirmation once. Preserve all failures. If a decision is changed after confirmation, create a newly frozen, disjoint confirmation set before making a fresh confirmation claim.

This pilot supports only scoped measured comparisons on ten classes: dog, chainsaw, crackling fire, helicopter, rain, crying baby, clock tick, sneezing, rooster and sea waves. Uploader separation does not certify different speakers or recording sessions. The separator's pretraining may overlap ESC/Freesound; this split isolates refiner training sources, not unknown foundation training data. Class labels are weak and do not prove pure isolated physical sources. Synthetic combinations of genuine recorded clips are controlled mixtures, not naturally captured multitrack ground truth.

Compare matched independent extractions, sequential residual extraction in the executed forward and reverse orders, unlearned consistency correction, trained refinement and another accessible separator on overlapping tasks. Primary quality measure is gain-sensitive waveform error of the rendered edit relative to `mixture + sum((gain-1)*clean_reference)`, plus SI-SDR, wrong target gain, absent-target energy, source-conditioned duplicate attribution and nontarget leakage. Report unity reconstruction and unchanged outside-span samples separately from separation quality. Aggregate paired recipe results with original-source-aware uncertainty; 20 confirmation recipes remain a small pilot.

Separate contract/robustness tests cover silence, malformed WAVs, clipping, rare/transient events, source identity ambiguity, identical/synonymous requests, anchor conflicts, locked-stem hashes, undo, permutations, simultaneous/sequential requests and long chunk joins. They do not silently enter model selection or replace quality evaluation. Natural recorded-scene examples have no clean multitrack references and support usability claims only unless additional ground truth exists. Stereo and speech/interview quality need separate data and evaluation.
